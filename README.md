# Tech Store Landing Page

صفحة هبوط (Landing Page) عصرية ومصممة خصيصاً لمتجر إلكتروني متخصص في بيع أجهزة الحاسوب والملحقات التقنية. تهدف الصفحة إلى تقديم المنتجات بطريقة احترافية تعزز من تجربة المستخدم وتساعد في زيادة معدل التحويل.

## التقنيات المستخدمة 🛠
- HTML5
- CSS3
- JavaScript (ES6+)

## المميزات 🚀
- **تصميم متجاوب:** تجربة تصفح مثالية على كافة الشاشات (Desktop, Tablet, Mobile).
- **واجهة مستخدم نظيفة (Clean UI):** تركيز عالي على المنتجات وتقليل أي تشتت بصري.
- **أداء سريع:** كود خفيف ومحسن لضمان سرعة تحميل الصفحة.
